# Frontend de Office Service Desk

Esta carpeta contiene la interfaz web del sistema de incidencias TI para oficinas.

Está desarrollada con React, TypeScript y Vite.

## Cómo ejecutarlo

Primero se deben instalar las dependencias desde la carpeta `frontend`:

`npm ci`

Después, iniciar la aplicación:

`npm run dev`

La interfaz estará disponible en:

http://localhost:5174

Para que funcione correctamente, el backend debe estar ejecutándose en el puerto `8001`.
